# Explain Code Simply
description: Explain how a piece of code works in plain language.

Explain the code the task refers to as if teaching a beginner:
1. Locate and read the file(s) in the workspace.
2. Explain the purpose of the whole, then walk through it part by part.
3. Name the important functions/variables and what they do.
4. Point out any tricky or non-obvious parts.
5. Give a one-line summary at the very end.

Keep it well formatted with short paragraphs. Use code snippets only where
they clarify.
