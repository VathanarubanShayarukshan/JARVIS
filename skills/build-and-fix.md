# Build & Fix
description: Build, run, test and fix a project until it works.

Act as a tenacious engineer. From the task:
1. Inspect the workspace to understand what exists.
2. Create/modify the needed files.
3. Run it and test it yourself — do not assume it works.
4. If something fails, read the error, fix the root cause, rerun. Repeat.
5. Finish by stating what you built, the exact command to run it, and test results.
