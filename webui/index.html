Models

End users never need an API key. Add a free key here once: Google Gemini, Groq or OpenRouter (all free, no card required). A local LLM found on the server also works automatically.

Providers

MCP servers

Give JARVIS extra tools (GitHub, browsers, memory…). Connect a hosted server with a single URL (Streamable HTTP / SSE), or run ready-made presets with npx — Node.js must be on the server. Tools appear automatically in every chat; type @ in the prompt to point a task at one server.

Your servers

+ Custom MCP server (URL or any stdio command)

Skills

Markdown instruction packs. Type / in the chat box and pick one — it is prepended to that task. Changes apply instantly, no restart.

Edit skill

Projects

Bundle instructions + knowledge files (notes, docs, specs). Every chat inside a project folder gets that context automatically. Create projects with the + in the sidebar, and drag any chat into a folder to move it.

    Chat names

    Every chat is named automatically from its first message. Rename any chat from its ⋯ menu in the sidebar, or by clicking the title at the top of the chat.

    Prompt commands

    /Skills — pick an instruction pack for this task, e.g. /code-review.
    @MCP servers — point the task at a connected server, e.g. @github.
    ⤓Push to background — the task keeps running on the server; close the window and resume later.
    ⏹Stop — cancels the agent itself on the server, not just the output on screen.
